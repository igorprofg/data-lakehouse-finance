<strong><h1>Projeto Data Lakehouse - Finanças</h1></strong>

<h3>Projeto de engenharia de dados focado na construção de uma arquitetura Lakehouse para ingestão, processamento, transformação e análise de dados financeiros obtidos via APIs públicas.</h3>

<h3>O objetivo deste projeto é implementar um pipeline de dados completo utilizando conceitos modernos de engenharia de dados, incluindo orquestração, conteinerização, arquitetura em camadas (Raw, Trusted e Refined), transformação de dados e integração com serviços em nuvem.</h3>

<br>

<h2>Tecnologias Utilizadas:</h2>

- Apache Airflow
- Docker
- PostgreSQL
- Python
- Polars
- dbt
- Google Cloud Storage
- Metabase

<br>

<h2>Fonte de dados</h2>
<h3>Os dados financeiros serão consumidos por APIs públicas com CoinGecko para garantir ingestão automatizada e atualização contínua.</h3>
